Job Description

We are looking for a talented Frontend Developer to join our team at Facebook. You will be responsible for building and maintaining modern web applications used by billions of people worldwide.

As a Frontend Developer, you will collaborate with cross-functional teams including designers, product managers, and backend engineers to create seamless user experiences.

What You'll Do

  • Develop new features and improve existing ones using React, TypeScript, and CSS
  • Collaborate with designers to implement pixel-perfect UI components
  • Optimise application performance and accessibility
  • Participate in code reviews and mentor junior developers
  • Contribute to our component library and design system

Benefits

  • Competitive salary and equity package
  • Remote-friendly work environment
  • Health, dental, and vision insurance
  • Annual learning & development budget
  • 401(k) matching programme
  • Flexible paid time off

Requirements

Minimum Qualifications

  • 3+ years of experience in frontend development
  • Strong proficiency in React, TypeScript, and modern CSS
  • Experience with responsive design and cross-browser compatibility
  • Familiarity with version control systems (Git)
  • Excellent problem-solving and communication skills

Preferred Qualifications

  • Experience with Next.js or similar frameworks
  • Knowledge of performance optimisation techniques
  • Familiarity with Webpack, Vite, or other build tools
  • Experience with testing frameworks (Jest, Cypress)
  • Open-source contributions
